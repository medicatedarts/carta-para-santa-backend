# Prototipo (referencia de impresión)

- `SantaLetter.dc.html`: carta de respuesta de Santa (página 1 de la impresión).
- `LetterArt.dc.html`: los 5 papeles de carta (página 2: copia de la carta del niño).

Son archivos de diseño con `{{variables}}`; se traducen a la plantilla HTML de impresión (`printTemplate.js` + `papeles/`). Ver `docs/ESPECIFICACION.md` §7.
